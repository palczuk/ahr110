# AHR110 Fieldcraft

Arquivos prontos para GitHub Pages.

## Estrutura
- `index.html` — página principal AHR 110, bilíngue.
- `unit1.html` — Unit 1: Heat, Temperature, and Pressure.
- `styles.css` — estilo visual responsivo inspirado no padrão Fieldcraft.
- `app.js` — navegação, idioma e busca da página principal.
- `unit1.js` — lógica do quiz e progressão de acertos.
- `questions.json` — banco das 25 questões.

## Publicação
1. Copie todos os arquivos para o mesmo diretório do repositório.
2. Faça commit/push.
3. Em GitHub: Settings → Pages → Deploy from branch.
4. Se o repositório já usa GitHub Pages, o `index.html` será a página inicial.

Não são necessárias bibliotecas externas.
